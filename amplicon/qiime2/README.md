# QIIME 2 workflows

Standard workflows for amplicon sequencing analysis using QIIME 2.

## Contents

This section includes workflows for:

- Data import
- Primer removal with Cutadapt
- Sequence quality assessment
- Denoising with DADA2
- Taxonomic classification
- Phylogenetic analysis
- Alpha diversity
- Beta diversity

## Notes

Parameters such as trimming and truncation lengths should be adjusted according to the sequencing run and read quality.
